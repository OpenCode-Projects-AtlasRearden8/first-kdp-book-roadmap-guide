# Checklists

Condensed, printable checklists for every phase. Each checklist corresponds to a chapter — use them while working, not just while reading.

## Project selection (Chapter 1)

- [ ] **Reader** named in one sentence (who is this specifically for?)
- [ ] **Problem** named in one sentence (what can they do afterward?)
- [ ] **Scope has a hard stop** — page budget and a pre-decided cut list
- [ ] **Topic lifespan** — still useful and true in 3 years, without depending on one product's current interface
- [ ] **Within your real knowledge** — you can teach it plainly, without borrowing authority
- [ ] **No permission traps** — no copyrighted quotes/images/logos needing clearance
- [ ] **Would recommend it to a friend** — your honest personal bar
- [ ] Wrong-shape ideas considered and *deliberately* abandoned (this is a milestone, not a failure)

## Kindle interior (Chapter 2, ebook)

- [ ] Title page — title, subtitle, author name as it should appear on Amazon
- [ ] Copyright page — year, name, rights statement; edition noted
- [ ] Disclaimer paragraph, if your book has educational boundaries
- [ ] Optional dedication
- [ ] TOC generated from Heading 1 styles and verified clickable
- [ ] Every chapter starts on a page break; images inline with alt text
- [ ] Back matter: glossary/resources/about-the-author, fully typed-out URLs
- [ ] All formatting done with Word/styles or app styles — no manual spacing hacks
- [ ] Previewed on desktop previewer **and** phone Kindle app
- [ ] File versioned (`title_v###_kdp.docx`), not `FINAL_final2.docx`

## Paperback interior (Chapter 2, print)

- [ ] Trim size chosen (e.g., 6"×9") and page size set to *exactly* the trim
- [ ] Controlled page count known (or near-final) *before* margin settings
- [ ] Outside margins and **gutter** looked up on KDP's spec page for *your* page count and bleed setting (don't guess)
- [ ] Chapters open where you want them (right-hand pages, as designed)
- [ ] TOC generated **after** final layout, with real page numbers
- [ ] All fonts embedded in the exported PDF
- [ ] All images at 300 DPI
- [ ] Bleed used only if content runs to the page edge
- [ ] Back matter URLs typed out (there is no "click" in print)
- [ ] **Physical proof ordered and read page-by-page**

## Pricing (Chapter 3)

- [ ] Ebook file size (MB) known — delivery fee estimated
- [ ] Paper price candidates computed at both 35% and 70% tiers with *current* KDP rates
- [ ] Paperback printing cost from **KDP's calculator**, not a blog's old number
- [ ] Per-sale royalty written down for ebook and paperback
- [ ] Out-of-pocket costs (editing, covers, proofs) totaled; break-even calculated
- [ ] Price chosen from the reader's value, not your feelings or a competitor's structure
- [ ] Price is one you can leave alone for a year
- [ ] No inflate-then-discount-forever plan
- [ ] Free/sample decided deliberately, not as a growth strategy

## Categories, keywords, description (Chapter 4)

- [ ] Categories all match the actual content
- [ ] All 7 keywords are real reader *phrases*, each 50 characters or fewer
- [ ] No trademark names, no subjective/superlative claims, no "free"/"bestseller" in keywords
- [ ] No other authors' or books' names anywhere in metadata
- [ ] Description opens with the reader's problem
- [ ] Description states concrete contents, chapter-level
- [ ] Description names who the book is *not* for
- [ ] No fake urgency, scarcity, or number-shopping anywhere
- [ ] Commitment made: **no purchased or incentivized reviews, ever**

## Launch week (Chapter 5)

- [ ] Proof read; errata list fixed in the final files
- [ ] One announcement post pre-written
- [ ] Live listing verified: title, author, price, description, categories, **Look Inside**
- [ ] Dashboard checked at a set time, not compulsively
- [ ] Errata log open from day one
- [ ] Real reader messages answered kindly and honestly
- [ ] No paid services, no promised-review schemes, no price games
- [ ] No same-week launches of books 2–4
- [ ] First readers asked privately, later, for *honest* reviews

## Royalties and paperwork (Chapter 6)

- [ ] Tax interview completed (W-9 US / W-8 non-US) — name/ID is exact
- [ ] Bank account set up and verified **before** launch
- [ ] Payee identity matches your copyright page decision (personal vs. LLC)
- [ ] `royalties/` folder created; monthly statements saved as they arrive
- [ ] Payment log spreadsheet: month, units, royalty, received date
- [ ] Receipts folder open for every business expense
- [ ] KDP ISBN decision made (free default recommended for most first books)
- [ ] Final manuscript + cover files archived in a labeled folder
- [ ] Taxes/LLC/filing questions routed to a qualified professional, not a guide
